DropKick 0.2.0 — 3막 구조 보드와 설정 기능이 생겼습니다.

- 3막 구조 보드 (세이브 더 캣 15단계): 1막·2막·3막 칸에 단계 카드를 놓고, 카드마다 이름·시놉시스·여러 씬을 적고 배치할 수 있습니다
  - 원고 씬 서랍에서 여러 씬을 골라 한꺼번에 끌어 놓기, 카드 안에서 순서 바꾸기, ⌘를 누른 채 끌어 다른 카드에 복제
  - 카드 추가·삭제, 3막 구조 초기화
- 프리셋: 기본 프리셋(3막 구조, 인물 양식)과 직접 만든 프리셋을 나눠 보여 주고, 새 프리셋은 문서 화면에서 만들 수 있습니다
- 설정 (메뉴 DropKick → 설정, ⌘,): 화면 테마, 표지 기본 작가 정보, 자동 저장 간격, 백업 보관 개수(최대 100개), 프리셋 내보내기·가져오기, 프로그램 전체 초기화
- 보기 → 화면 비율 (80%, 100%, 120%, 150%)
- 파일 → 프로젝트 위치 열기
- 맨 위 제목 줄에 "프로젝트 - 폴더 - 문서" 위치를 보여 주고, 오른쪽에 DropKick!을 표시
- 사이드바 아이콘을 SF 심볼 목록에서 고를 수 있습니다
- DropKick 정보 창에 GitHub 링크와 저작권 문구 추가
