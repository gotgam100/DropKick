DropKick 0.6.0 — 외부 시나리오 가져오기, 여러 스크립트, 스크립트 설정

- 외부 시나리오 가져오기: 파일 메뉴에서 PDF, Word(.docx), 한글(.hwpx) 시나리오를 불러와 DropKick 원고로 바꿉니다. AI 없이 글자 위치와 모양으로 씬헤딩·인물·대사·지문·괄호지문·서브 헤더를 나눕니다. #1, S#1, SC#1, 1. 같은 씬 번호는 떼고 새로 매기고, (길동)처럼 괄호로 쓴 인물 이름과 INS. / INS> 줄도 알아봅니다
- 가져오기 전 확인: 첫 쪽이 표지인지, 인물 이름 위치, 글씨체가 달라 헷갈린 줄의 스타일을 먼저 물어보고 그대로 반영합니다. 가져온 뒤에는 한눈에 보는 결과 창이 요약과 확인하면 좋은 곳을 알려 줍니다
- 스크립트를 여러 개 둘 수 있습니다: 새 스크립트, 복제해서 새 버전 만들기, 이름 바꾸기, 지우기. 통계·씬 목록·내보내기·표지는 지금 열린 스크립트를 따르고, 메모와 수정고는 스크립트마다 따로 가집니다. 문서와 폴더를 한 스크립트 전용으로 정할 수도 있습니다
- 스크립트 설정 창: 표지 항목을 켜고 끄기, 씬 번호 시작 숫자, PDF 워터마크를 스크립트마다 따로 정합니다
- 새 프로젝트의 기본 사이드바가 개요(시놉시스, 3막 구조 양식) / 메인 스크립트 / 인물 설정 / 메모 / 기타 / 구분선 / 수정고로 바뀌었습니다. 구분선은 우클릭으로 더할 수 있습니다
- 시나리오 작성 가이드의 예시 스크립트가 실제 작품 원고로 바뀌었습니다. 1씬 전체를 스크롤해서 볼 수 있습니다
- 스타일 순서가 씬헤딩 → 액션 → 인물 → 대사 → 괄호지문 → 서브 헤더 → 전환으로 바뀌었습니다(단축키 ⌘1–⌘7도 같은 순서). Tab으로 이 순서대로 바꾸고, 괄호지문이 되면 글이 자동으로 ( ) 안에 들어갑니다
- 씬헤딩 자동 완성: ` - ` 뒤에 띄어쓰기를 한 다음에만 시간대(낮, 밤)를 추천합니다
- 메뉴: 스타일 메뉴에 단축키가 다른 메뉴처럼 보입니다. ⌘+ / ⌘-로 화면 비율을 단계별로 바꿉니다. 보기 메뉴에 집중 모드가 들어갔고, 파일 메뉴에 구분선이 생겼습니다. DropKick 메뉴의 가리기 항목은 없앴습니다
- 툴바: 스크립트 설정·집중 모드·작성 가이드가 아이콘 버튼 세 개로 나란히 놓였습니다
- 한글 입력 중 Enter를 누르면 줄이 두 번 바뀌던 문제, 빈 원고에서 처음 쓰는 한글 글자가 깨지던 문제를 고쳤습니다
- 파일 메뉴의 최근 프로젝트 열기에 최근 프로젝트가 나오지 않던 문제를 고쳤습니다
- 통계 창이 좁아져도 글자가 줄바꿈되지 않도록 최소 너비를 지킵니다
