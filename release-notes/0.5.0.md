DropKick 0.5.0 — 내보내기 창, 씬 끌어 옮기기, 집중 모드

- 내보내기 창: PDF·Word로 내보낼 때 무엇을 담을지 고릅니다. 원고와 표지 외에 인물 설정·메모 같은 다른 문서와 3막 구조(단계와 요약을 표로)를 뒤에 이어 붙일 수 있습니다
- 씬 끌어서 순서 바꾸기: 사이드바의 씬 목록에서 씬을 끌어 다른 씬 앞이나 뒤에 놓으면 원고 본문과 씬 번호가 함께 바뀝니다. ⌘Z 한 번으로 되돌릴 수 있습니다
- 찾아 바꾸기: 한국어 창으로 바꾸고 보기 좋게 다듬었습니다. 제목줄을 끌어 원하는 곳으로 옮길 수 있습니다
- 씬헤딩 자동 완성: 씬헤딩을 입력할 때 앞에서 쓴 장소를 추천합니다. 내부·외부와 상관없이 장소 이름으로 찾고, ` - ` 뒤에는 시간대(낮, 밤)를 추천합니다. 설정에서 끌 수 있습니다
- 원고 메모 모아 보기: 사이드바에 메모 목록이 생겼습니다. 메모를 누르면 그 글로 이동합니다
- 통계: 장소별 씬 목록과, 인물별로 등장하는 씬 목록을 볼 수 있습니다
- 집중 모드: 툴바의 더보기 메뉴나 ⇧⌘F로 툴바·사이드바·통계를 숨기고 원고만 봅니다. Esc로 끝냅니다
- 최근 프로젝트 열기: 파일 메뉴에서 최근에 연 프로젝트를 바로 엽니다
- 툴바 정리: 표지와 가이드는 더보기 메뉴로 묶고, 선택된 버튼은 주황색으로 보입니다. 사이드바·화면 나누기·통계 버튼의 단축키 표시는 없앴습니다. 프리셋은 문서 양식이라는 이름으로 바꿨습니다
- 메뉴: DropKick 메뉴의 서비스 항목을 없애고, 자매품 항목(개발자의 다른 앱)을 추가했습니다. 오른쪽 위 DropKick!을 누르면 정보 창이 열립니다
- 설정: 탭을 정리하고 추가한 양식 관리 항목을 없앴습니다
- 3막 구조 카드의 배경이 해당 막의 색으로 보입니다
- 메모 창이 열려 있는 동안 친 글자가 원고에 들어가 원고가 바뀌던 문제를 고쳤습니다
- 드래그로 글을 고를 때 페이지 아래 여백과 페이지 번호까지 칠해지던 문제를 고쳤습니다
- 설정·가이드 창과 이벤트를 주고받는 부분이 중복으로 연결될 수 있던 문제를 고쳤습니다
