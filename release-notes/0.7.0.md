DropKick 0.7.0 — 막·시퀀스·씬 요약, 글자 꾸미기, 쓰기 도움말

새로 생긴 것
- 막 · 시퀀스 · 씬 요약: 줄 맨 앞에서 `# `(막), `## `(시퀀스), 씬헤딩 아래에서 `= `(씬 요약)을 치면 인쇄되지 않는 메모 줄이 됩니다. 사이드바 씬 목록이 막 ▾ 시퀀스 ▾ 씬 ▾ 요약으로 묶여 접고 펼 수 있고, 스크립트 설정에서 켜면 PDF·Word에도 넣을 수 있습니다
- 글자 꾸미기: 굵게(⌘B) · 기울임(⌘I) · 밑줄(⌘U), 액션 줄 가운데 정렬(⌘E)과 들여쓰기(⌘] ⌘[). 우클릭 → "글자 모양"에서도 고를 수 있습니다
- 쓰기 도움말: 화면 아래 상태 막대에 지금 요소와 ⏎·Tab을 누르면 바뀔 요소가 보이고, 요소마다 처음 쓸 때 한 번만 짧은 안내가 뜹니다 (설정 → 화면에서 끌 수 있습니다)
- 작성 가이드를 새로 만들었습니다. 요소 카드를 누르면 예시 원고의 그 줄로 이동하고, 2쪽 '이야기 구조'에서 막·시퀀스·씬 요약을 설명합니다
- Fountain 보기: 상태 막대의 "Fountain" 버튼을 누르면 원고 위에 Fountain 기호(. @ > # 등)를 겹쳐 보여 줍니다
- 사이드바 오른쪽 경계선을 끌어 폭을 바꿀 수 있습니다 (두 번 누르면 기본 폭)
- 씬헤딩이 "실내. 장소 - 시간대" 모양이 아니면 물결 밑줄로 알려 줍니다
- 통계에 장소 · 글자 수 칸이 생겼습니다

쓰기가 편해진 것
- 글이 있는 줄 맨 앞에서 Enter를 누르면 위에 같은 요소의 빈 줄이 생기고, 씬헤딩 맨 앞에서 Backspace를 누르면 앞 줄과 합치지 않고 액션이 됩니다
- 씬 요약은 줄 끝까지 채워 글자 단위로 줄을 바꿉니다
- 씬 번호는 어디서나 '1.'로 보입니다 ('#'은 막 기호라서)
- 같은 이름의 프로젝트에 저장할 때 덮어쓸지 · 둘 다 둘지 묻고, 덮어써도 기존 것은 휴지통으로 갑니다

고친 것
- 트랙패드 탭이 한 번에 안 눌리거나, 사이드바 씬을 누르기만 했는데 순서가 바뀌던 문제
- 짝이 없는 별표(*)와 밑줄(_)이 사라지던 문제 (이제 그대로 보이고 인쇄됩니다)
- 막·시퀀스·씬 요약이 많으면 원고가 쪽 번호를 가리던 문제
