DropKick 0.7.0 — 쓰기 도움말, 새 작성 가이드, 트랙패드 탭 고침

- 트랙패드로 탭하면 한 번에 안 눌리거나, 사이드바 씬을 누르기만 했는데 순서가 바뀌던 문제를 고쳤습니다
- 프로젝트를 다시 열면 막·시퀀스·씬 요약 줄이 사라지던 문제를 고쳤습니다
- 쓰기 도움말: 화면 아래 상태 막대에 지금 요소와 ⏎·Tab을 누르면 바뀔 요소가 보이고, 요소마다 처음 쓸 때 한 번만 원고 오른쪽 위에 짧은 안내가 뜹니다 (설정 → 화면에서 끌 수 있습니다)
- 작성 가이드를 새로 정리했습니다. 요소 카드를 누르면 예시 원고의 그 줄로 이동하고, 2쪽은 막·시퀀스·씬 요약을 다루는 '이야기 구조'입니다
- 짝이 없는 별표(*)와 밑줄(_)은 그대로 보이고 인쇄됩니다. 짝이 맞아도 글자로 쓰려면 앞에 \를 붙입니다
- 씬 요약은 글자 단위로 줄 끝까지 채워 줄을 바꿉니다
- 막·시퀀스·씬 요약이 많아도 원고가 쪽 번호를 가리지 않습니다
- 씬 번호는 어디서나 '#1.' 대신 '1.'로 보입니다
- 같은 이름으로 저장해 덮어쓸 때 새 저장이 끝난 뒤에야 기존 프로젝트를 휴지통으로 보내, 저장에 실패해도 잃지 않습니다
- 통계에 장소·글자 수 칸이 생겼고, 상태 막대는 페이지·씬·장소 수와 Fountain 보기 버튼만 남겼습니다
- 작은 화면에서는 작성 가이드 창이 화면에 맞게 줄어듭니다
