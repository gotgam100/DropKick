DropKick 0.6.3 — 다시 열면 보던 자리로, 메뉴와 버튼 정리

- 프로젝트를 다시 열면 스크립트마다 마지막에 보던 자리(커서와 화면 위치)로 돌아갑니다. 글을 고치지 않고 읽기만 했어도, 닫거나 업데이트하기 직전에 그 자리를 기억합니다
- 화면 아래 글자 수 줄에서 '공백 제외'를 빼고 '장소 N개'를 넣었습니다. '실내. 장소명'까지 같으면 같은 장소로 세고, 세부 장소와 시간대는 달라도 됩니다
- 메뉴 글을 간단하게 다듬었습니다
  - 편집 메뉴와 우클릭 메뉴가 '잘라내기 / 복사 / 붙이기'로 같아졌고, '실행 복귀'는 '다시 실행'으로 바뀌었습니다
  - 내보내기 메뉴는 'PDF…', 'Word…', 파일 메뉴는 'Finder에서 보기', '백업 보기'입니다. 가져오기 앞에 구분선을 넣었습니다
  - 보기 메뉴의 '사이드바'와 '통계'는 켜져 있으면 ✓가 보입니다
  - 화면 비율 메뉴는 '확대 / 축소 / 기본 크기(⌘0)'만 남겼습니다
- 사이드바 우클릭 메뉴가 '+ 새 문서', '+ 새 폴더', '+ 새 스크립트', '+ 양식', '+ 구분선', '복제'로 간단해졌고, 하위 메뉴 화살표가 커졌습니다
- 통계의 인물마다 있던 버튼 3개를 줄 오른쪽의 ⋯ 하나로 모았습니다 (설정 열기 · 이름 바꾸기 · 등장 씬)
- 수정고 화면에서는 'PDF로 내보내기'와 '지우기'가 ⋯ 메뉴로 들어갔습니다
- 설정 창의 탭 이름이 짧아졌고, 스크립트 설정의 두 번째 탭은 '씬 번호 · 워터마크'입니다
